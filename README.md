# Flowstate

A thoughtfully animated, responsive task manager designed to make planning feel lighter.

## Features
- Create, edit, complete, and delete tasks
- Organize tasks into Personal, Work, and Ideas lists
- Filter by status and priority; search titles, notes, and lists
- Optional due dates with today and upcoming views
- Daily progress ring and task statistics
- Light/dark theme and browser-local persistence
- Keyboard shortcuts: N to create a task, / to search
- Reduced-motion support

## Run locally
No build step or dependencies are required. Open index.html in a modern browser or serve this folder with any static file server.

## Motion
Flowstate uses staggered task entrances, animated completion feedback with a small celebration, eased hover and press states, an animated progress ring, and a refined dialog transition. Motion respects prefers-reduced-motion.
